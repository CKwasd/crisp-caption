# Demo

This folder contains short feature demos for the README.

## Browser Control Panel

![crisp-caption live Japanese subtitle control panel](ControlPanel.png)

The browser control panel selects `Tab audio` or `Microphone` capture, shows live status (capture, CrispASR, profile, translator, latency), counters, and the live transcript with translations.

## Transparent Desktop Overlay

The transparent always-on-top Japanese subtitle overlay. Watch a video in a browser tab and get live captions plus translation in a floating window.

https://github.com/user-attachments/assets/36bbb83d-79f2-49e7-a71c-f146bd5ca058

[Open overlay.mp4](overlay.mp4)

## OBS Browser Source Overlay

A subtitle overlay for OBS, added as a transparent Browser Source (`http://127.0.0.1:8765/obs-overlay`) sized to your canvas (e.g. `1920 x 1080`).

https://github.com/user-attachments/assets/9b6e92a7-37d3-451e-bce8-c43d47ac3544

[Open obs-subtitle.mp4](obs-subtitle.mp4)

The local MP4 links are kept as fallback files inside the repository.
